ASSET STRATEGY — INSTALLABLE PWA PROTOTYPE (v0.2)

This is a static, browser-based prototype. It uses fictional Farringdon property data.

PUBLISH ON GITHUB PAGES (FREE):
1. Sign in to github.com, create a PUBLIC repository, e.g. asset-strategy.
2. Upload ALL FIVE files from this folder to the root of that repository: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png. (Do not upload only the ZIP.)
3. In repository Settings > Pages, choose Deploy from a branch; Branch: main, Folder: / (root); Save.
4. When GitHub displays the live HTTPS URL, open it in Safari on your iPad. It typically looks like https://USERNAME.github.io/asset-strategy/ but use the exact URL GitHub gives you.
5. In Safari tap Share > Add to Home Screen > Add. Launch the new Home Screen icon for the full-screen experience.

DATA: Changes are saved in local browser storage on that device/browser; they are NOT synced between devices. Export inputs (JSON) regularly and import on another device if required. Clearing website data can erase saved appraisals. This prototype has no server and no login.

LIMITATIONS: This prototype models unlevered returns only; it is not independently audited and does not yet support financing, disposal/reinvestment, or a portfolio connection. Review timing, lease assumptions, cash-flow calculations, and costs before professional use. Hosting on a public URL does NOT mean that your locally stored inputs are published, but do not use confidential property data in an unreviewed prototype.
